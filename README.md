# Iron Core Builders Premium React Website

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Main updates

- Official Iron Core Builders PDF logo converted to transparent PNG and used in the navbar and footer.
- Full supplied house image displayed in the hero with a layered cinematic animation.
- Supplied road image used only as the contact-section background with slow motion and light-sweep effects.
- Responsive React + Tailwind CSS layout, service dropdown, JCB section, project popup gallery, map and enquiry form.
